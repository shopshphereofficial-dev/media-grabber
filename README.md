# Media Grabber

A personal-use media downloader for Android powered by [yt-dlp](https://github.com/yt-dlp/yt-dlp)
(via [youtubedl-android](https://github.com/JunkFood02/youtubedl-android)).

Downloads videos/posts from YouTube, Instagram, Facebook and 1000+ other sites
in the original available quality, with no watermark and no ads.

## Usage
1. Copy any video/post link (Share -> Copy link)
2. Open Media Grabber, tap PASTE, then DOWNLOAD
3. File is saved in your phone's Downloads folder

## Important
This app is for **personal use of your own content** only. Downloading other
people's copyrighted content and re-sharing it is a copyright violation, and
this app must not be redistributed (Play Store policy prohibits such apps).
